⚡ AvoidArc

개인정보처리방침

최종 수정일: 2026년 8월 7일

AvoidArc(이하 "서비스")는 웹 브라우저에서 즐기는 무료 게임입니다. 이 문서는 서비스가 무엇을 수집하고, 무엇을 수집하지 않는지 설명합니다.

먼저 알아두실 것

이 서비스는 이메일 주소를 받지 않습니다. 구글 로그인을 쓰지만 구글에 요청하는 권한은 openid 하나뿐이라, 서비스는 회원님의 이메일·이름· 프로필 사진을 볼 수 없습니다. 광고나 분석 도구도 넣지 않았습니다.

1. 수집하는 항목

항목언제 생기나왜 필요한가
구글 계정 고유번호 구글로 로그인할 때 다음에 접속했을 때 같은 사람임을 알아보기 위해. 뜻을 알 수 없는 숫자 문자열이며 이것만으로는 누구인지 알 수 없습니다.
닉네임 회원님이 직접 정할 때 랭킹과 대전 상대에게 표시
게임 기록 게임을 할 때 버틴 시간, 승패, 연승, 대전 상대와 일시. 랭킹과 전적 화면에 씁니다.
로그인 쿠키 로그인할 때 로그인 상태 유지. 60일 뒤 만료되며, 로그아웃하면 즉시 삭제됩니다.

2. 수집하지 않는 항목

  • 이메일 주소, 실명, 전화번호, 생년월일, 프로필 사진
  • 녹음한 목소리 — 점프 소리를 녹음하면 그 파일은 회원님의 브라우저 안에만 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.
  • 광고 식별자, 위치 정보, 다른 사이트에서의 활동

3. 접속 기록

서비스는 같은 곳에서 기록을 반복해서 올리는 것을 막기 위해 접속 IP 주소를 메모리에 잠시만 둡니다. 데이터베이스에 저장하지 않으며, 서버를 다시 시작하면 사라집니다.

이와 별개로 웹 서버는 통상적인 접속 기록(시각, 요청한 주소, IP)을 로그 파일에 남깁니다. 이는 장애 대응과 침해 시도 확인 목적으로만 사용하며, 다른 정보와 결합하지 않습니다.

4. 제3자 제공

회원님의 정보를 누구에게도 판매하거나 제공하지 않습니다. 다만 서비스 운영을 위해 다음을 이용합니다.

  • Google LLC — 로그인 처리. 회원님이 구글에 직접 로그인하며, 서비스는 결과로 고유번호만 받습니다.
  • Cloudflare, Inc. — 접속 경로 보호. 트래픽이 이곳을 거쳐 서버에 도달합니다.
  • Vultr Holdings LLC — 서버 임대. 서버는 대한민국 서울에 있습니다.

5. 보관 기간

계정과 게임 기록은 회원님이 삭제를 요청할 때까지 보관합니다. 로그인 세션은 60일 뒤 자동으로 만료됩니다.

6. 회원님의 권리

언제든지 본인의 계정과 기록을 삭제해 달라고 요청할 수 있습니다. 요청하시면 계정, 닉네임, 게임 기록, 대전 기록을 모두 지웁니다. 이미 마감된 시즌의 명예의 전당 기록도 함께 지웁니다. 삭제 후에는 되돌릴 수 없습니다.

7. 안전조치

  • 모든 통신은 HTTPS 로 암호화됩니다.
  • 로그인 쿠키는 HttpOnly 로 설정되어 자바스크립트가 읽을 수 없습니다.
  • 데이터베이스는 매일 자동으로 백업합니다.
  • 비밀번호를 직접 다루지 않습니다. 로그인은 전적으로 구글이 처리합니다.

8. 만 14세 미만 이용자

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 아동의 정보가 수집된 사실을 알게 되면 즉시 삭제합니다.

9. 변경 고지
